Burhan بُرهان

AI-powered research intelligence platform

Burhan turns a set of research papers into a structured, evidence-backed model of a research field — a Research Digital Twin of methods, datasets, metrics, findings, limitations and research gaps that can be explored and questioned.

Problem
Researchers need to see how a field behaves across many papers — which methods and datasets recur, which limitations repeat, where the gaps are. Most tools work one document at a time.
Solution
A FastAPI pipeline parses PDFs, uses an LLM to extract validated scientific entities, links them into a knowledge graph and reasons across papers — surfaced in a Next.js dashboard.
  • Multi-PDF ingestion & parsing
  • LLM extraction validated with Pydantic
  • Typed scientific knowledge graph
  • Cross-paper method & dataset analysis
  • Evidence-backed research gap discovery
  • Grounded Q&A with citations & confidence

Study Assistant RAG

A retrieval-augmented generation system that answers questions from PDF documents by combining semantic search with an LLM.

Problem
Answer questions grounded in the content of specific PDF documents.
Solution
A backend pipeline that extracts, chunks and embeds PDF text into ChromaDB, retrieves and reranks passages, and generates answers with Groq's LLM API.
  • Text extraction, chunking and embeddings
  • Vector storage in ChromaDB with reranking for retrieval accuracy
  • FastAPI REST API for PDF uploads, questions and document summaries

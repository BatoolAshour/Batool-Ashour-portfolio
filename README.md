# Batool Ashour — Portfolio

My personal portfolio site. Built with plain HTML, CSS, and JS — no dependencies, no build step.

**Live site:** [(https://batoolashour.github.io/Batool-Ashour-portfolio/)](https://batoolashour.github.io/Batool-Ashour-portfolio/)

## Structure

```
index.html                  Home page
projects/burhan/index.html  Burhan case study (/projects/burhan/)
assets/css/site.css         Shared styles
assets/js/site.js           Shared behaviour (nav, reveal, showcase, lightbox, contact form)
assets/projects/burhan/     Burhan screenshots (WebP)
assets/*.jpg / *.webp       Other project images (WebP served, JPG fallback)
```

## Run locally

```bash
python3 -m http.server 8080
```

Then open http://localhost:8080.

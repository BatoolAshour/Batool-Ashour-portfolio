Burhan بُرهان

AI-powered research intelligence platform

Burhan reads a set of research papers, extracts structured scientific knowledge from each one and connects it into a Research Digital Twin — a graph of papers, methods, datasets, metrics, findings, limitations and research gaps. Instead of answering questions about one PDF at a time, it reasons across papers to show what they collectively report, which limitations they share and where the gaps are.

01

The problem

Researchers don't only need to read papers — they need to understand how a research field behaves across many papers. Most research tools optimise individual tasks such as search, summarisation or PDF question answering. They don't build a structured model of the field that grows as new papers are added.

  • Which methods are used, compared and improved?
  • Which datasets and metrics define the field?
  • Which findings are supported by evidence?
  • Which claims contradict each other?
  • Which limitations repeat across studies?
  • Which research gaps are actionable?
02

How it works

A staged pipeline in a FastAPI backend. Each run takes five PDFs from one domain and produces a Research Digital Twin that the Next.js frontend renders as a dashboard and interactive graph.

  1. Ingest & parse

    PDFs are stored per run and parsed with Docling when available, falling back to PyMuPDF. Title, authors, year, abstract and sections are detected.

    FastAPI · PyMuPDF · Docling

  2. Extract structured knowledge

    An LLM in JSON mode extracts problem, objective, method, dataset, metrics, findings, limitations, future work and evidence quotes — validated against Pydantic schemas, with a heuristic fallback.

    Groq · gpt-oss-120b · Pydantic

  3. Build the twin

    Extracted entities become typed graph nodes and relationships. Methods, datasets and metrics are merged across papers so shared concepts connect.

    Knowledge graph · Neo4j (optional)

  4. Reason across papers

    Cross-paper analysis ranks the most common methods, datasets and metrics, groups repeated limitation themes and checks findings for contradictions.

    Cross-paper analysis

  5. Discover research gaps

    Limitations that recur across papers are aggregated into an evidence-backed research gap, linked to its supporting papers and source quotes.

    Gap detection

  6. Answer with evidence

    Questions retrieve matching findings, quotes and limitations; the LLM answers citing papers, and a confidence score marks the answer accepted, needing more evidence, or insufficient.

    Grounded Q&A · confidence scoring

Paper USES Method Paper EVALUATES Dataset Paper REPORTS Metric Paper CLAIMS Finding Paper STATES Limitation Method COMPARES Method Paper SUGGESTS ResearchGap

Each run is saved as a JSON artifact. PostgreSQL (metadata), Qdrant (evidence vectors) and Neo4j (graph) persistence switch on when configured.

03

Key features

What the current MVP implements.

Scientific PDF ingestion

Multi-file upload of research papers with page text parsing, metadata detection and section splitting.

Structured paper extraction

Nine scientific fields per paper, extracted by an LLM and validated with strict Pydantic schemas before entering the twin.

Scientific knowledge graph

Seven node types and typed relationships, explorable in an interactive React Flow graph with node inspection.

Cross-paper analysis

Most common methods, datasets and metrics, repeated limitations and contradiction checks across the paper set.

Research gap discovery

Gaps built from limitations shared by multiple papers, shown with the supporting papers and the evidence behind them.

Evidence-grounded answers

Answers cite papers and list the evidence retrieved, with a confidence score and validation status.

07

What's next

The project's direction is an agentic research scientist: dedicated agents for planning, extraction, evidence verification, cross-paper reasoning and gap discovery. On the roadmap — not yet in the MVP:

  • Multi-agent orchestration of the pipeline
  • Semantic embeddings for evidence retrieval
  • Continuous twin updates as new papers are added
  • Richer graph analytics and scholarly data integrations
